# 🍽️ Annai Family Restaurant - Official Website

A premium, fully responsive, and highly optimized business website built for a real-world client, **Annai Family Restaurant** located in Tiruchengode, Tamil Nadu. This project was developed to provide the restaurant with a strong digital presence, showcasing their menu, gallery, events, and contact information, while ensuring top-tier search engine visibility.

## 🚀 Live Demo
👉 **[Visit Live Website](https://annai-family-restaurant.vercel.app/)**
*(Successfully indexed and verified on Google Search Console)*

## 📌 Project Overview
This project is a complete Single Page Application (SPA) featuring a modern, mobile-first design inspired by the "Saffron & Stone" aesthetic. The color palette focuses on warm cream, rich terracotta, and deep charcoal to reflect a premium dining experience.

## ✨ Key Features

*   **Modern UI/UX Design:** Clean, elegant layout with smooth scrolling navigation between sections.
*   **Mobile-First Responsive:** Fully optimized for mobile, tablet, and desktop views. Uses Tailwind CSS grid/flex utilities for dynamic layout adjustments.
*   **Comprehensive Menu Display:** Categorized menu (Starters, Soups, Egg Recipes, Main Course, Rolls, Veg/Non-Veg Gravies, Beverages, etc.) with a structured layout and distinct imagery.
*   **Event Showcase Section:** A dedicated "Celebrate With Us" section highlighting services like Birthday Parties, Weddings, Baby Showers, DJ Events, and Fire Camps.
*   **Interactive Gallery:** A visually appealing grid showcasing restaurant interiors, outdoor seating, and food spreads.
*   **Contact & Location:** Integrated Google Maps iframe for exact location (9VQV+2Q, Tiruchengode) and clickable phone numbers (`tel:` links) for immediate customer interaction.
*   **Custom Verification:** Implemented Google Search Console meta-tag verification for SEO tracking.

## 🔍 SEO (Search Engine Optimization)
This project was built with a strong focus on Local SEO, ensuring the restaurant is discoverable online:
*   **Next.js Metadata:** Custom `title`, `description`, and OpenGraph tags for social sharing.
*   **Structured Data (JSON-LD):** Added `Restaurant` schema markup (name, address, opening hours, cuisine) to help Google understand the business better.
*   **Sitemap & Robots:** Automatically generated `sitemap.xml` and `robots.txt` using Next.js App Router.
*   **Google Search Console:** Property successfully verified, sitemap submitted, and website indexed by Google.

## 🛠️ Tech Stack

*   **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom Color Palette)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Fonts:** Google Fonts (Playfair Display for Headings, Inter for Body)
*   **Hosting/Deployment:** [Vercel](https://vercel.com/)
*   **Version Control:** Git & [GitHub](https://github.com/danya191106/Annai-family-restaurant)
